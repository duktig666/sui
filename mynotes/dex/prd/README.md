## 🎯 产品定位

Hermes DEX 是一个基于 Cosmos SDK 和 CometBFT 构建的**去中心化永续合约交易所**,提供:

- 🔄 **链上订单簿交易**: 类似中心化交易所的交易体验
- 🚀 **高性能匹配引擎**: 每个区块处理 1,000+ 订单
- 🛡️ **MEV 保护**: 确保公平交易环境
- 💰 **自动化做市**: Megavault 提供稳定流动性
- 🔓 **无需许可上市**: 任何人都可以创建市场
- 📊 **透明的资金费率**: 去中心化价格锚定机制

## 📊 产品功能总览

### 1. CLOB 模块 - 核心交易引擎

**产品定位**: 中央限价订单簿,Hermes 的核心交易引擎

**核心功能**:
- **订单放置**: 支持短期、长期、条件订单等多种类型
- **订单匹配**: 价格-时间优先,确定性匹配
- **订单取消**: 主动取消和批量取消
- **自动清算**: 保证金不足自动强制平仓
- **MEV 保护**: 速率限制、权益层级限制
- **订单簿查询**: 实时订单簿和成交记录

**关键公式**:
- 维持保证金要求 = 仓位价值 × 维持保证金率
- 清算触发条件: 账户总资产 < 维持保证金要求
- 订单配额 = GetQuotaForEquityTier(账户净资产)

**目标用户**:
- 普通交易者: 使用限价单交易
- 专业交易者: 使用高级订单类型
- 做市商: 提供流动性赚取价差

**详细文档**: [clob_prd.md](clob_prd.md)

---

### 2. Perpetuals 模块 - 永续合约配置

**产品定位**: 永续合约配置中心,管理合约参数和资金费率

**核心功能**:
- **合约定义**: 创建和管理永续合约
- **流动性层级**: 多档风险等级,不同保证金要求
- **资金费率计算**: 两层周期机制 (1 分钟采样 + 1 小时结算)
- **资金费率结算**: 多空之间转移资金费
- **OIMF 机制**: 基于未平仓合约量动态调整保证金
- **未平仓合约量追踪**: 实时监控市场风险敞口

**关键公式**:
- 溢价 = (指数价格 - 预言机价格) / 预言机价格
- 资金费率 = Clamp(8 × 平均溢价, 下限, 上限)
- 资金费用 = 仓位价值 × 资金费率 × (1小时 / 8小时)
- OIMF = (OI - 下限) / (上限 - 下限) × 100% (线性插值)
- 调整后保证金率 = 基础保证金率 + OIMF × (基础保证金率 - 维持保证金率)

**目标用户**:
- 所有交易者: 受资金费率和保证金要求影响
- 套利者: 利用资金费率套利
- 大户: 受 OIMF 影响,需要更多保证金

**详细文档**: [perpetuals_prd.md](perpetuals_prd.md)

### 3. Listing 模块 - 市场上市管理

**产品定位**: 无需许可的市场创建系统

**核心功能**:
- **一键市场创建**: 单个交易创建完整市场
- **默认参数配置**: 根据市值自动选择流动性层级
- **Vault 存款门槛**: 防止垃圾市场
- **市场硬上限保护**: 限制市场总数
- **市场查询**: 查询市场列表和详情

**关键公式**:
- 存款验证: 存款金额 >= 最低 Vault 存款要求

**目标用户**:
- 项目方: 为代币创建永续合约市场
- 社区成员: 为热门代币创建市场
- 做市商: 为新市场提供流动性

**详细文档**: [listing_prd.md](listing_prd.md)

### 4. Prices 模块 - 价格预言机集成

**产品定位**: 去中心化价格数据源

**核心功能**:
- **Slinky Oracle 集成**: 通过 Vote Extensions 提交价格
- **价格验证**: Towards/Crossing 条件防止异常价格
- **实时价格查询**: 每个区块更新价格
- **价格历史查询**: 查询价格时间序列

**关键公式**:
- Towards 条件: |新价格 - 指数价格| <= |旧价格 - 指数价格|
- Crossing 条件: newDelta <= sqrt(oldDelta × tickSize)

**目标用户**:
- 所有交易者: 依赖准确价格进行交易和清算
- 系统模块: CLOB、Perpetuals、Vault 等依赖价格
- 验证器节点: 提交价格投票

**详细文档**: [prices_prd.md](prices_prd.md)

### 5. Stats 模块 - 交易统计

**产品定位**: 交易统计和手续费分级系统

**核心功能**:
- **30 天滚动窗口统计**: 自动清理过期数据
- **Taker/Maker 分离**: 区分主动和被动成交
- **手续费分级**: 交易量越大,费率越低
- **联盟费用追踪**: 推荐返佣机制
- **全局统计**: 系统总交易量

**关键公式**:
- 手续费 = 交易金额 × 手续费率
- 手续费率 = GetFeeRate(30天交易量, Taker/Maker)
- 推荐返佣 = 被推荐者手续费 × 推荐分成比例

**目标用户**:
- 高频交易者: 通过交易量获得手续费折扣
- 做市商: Maker 交易获得更低费率
- 推荐者: 通过推荐获得返佣

**详细文档**: [stats_prd.md](stats_prd.md)

---

### 6. Vault 模块 - 自动化做市

**产品定位**: 自动化做市和流动性管理系统

**核心功能**:
- **Megavault 存款**: 用户存入 USDC,获得份额
- **Megavault 提款**: 赎回份额,提取 USDC,需等待解锁期
- **自动做市**: 每个区块自动刷新订单,提供流动性
- **盈亏分配**: 份额价值随 Vault 盈亏动态调整

**关键公式**:
- 份额价值 = Vault 总净值 / 总份额数
- 存款份额 = 存款金额 / 份额价值
- 提款金额 = 提款份额 × 份额价值 (解锁时)
- 买单价格 = 预言机价格 × (1 - 价差/2)
- 卖单价格 = 预言机价格 × (1 + 价差/2)
- 订单大小 = Vault 净值 × 仓位百分比 / 预言机价格

**目标用户**:
- 被动投资者: 无需专业知识,自动做市
- 小额投资者: 资金不足以独立做市
- 风险分散者: 分散到多个市场
- 交易者: 受益于充足流动性

**详细文档**: [vault_prd.md](vault_prd.md)

---

### 7. Leverage 模块 - 杠杆管理

**产品定位**: 杠杆倍数管理系统

**核心功能**:
- **杠杆设置**: 用户自定义杠杆倍数 (1x - 100x)
- **杠杆调整验证**: 验证保证金充足性
- **保证金计算集成**: 影响订单放置和持仓
- **杠杆查询**: 查询当前杠杆设置

**关键公式**:
- 初始保证金率 (IMR) = 1 / 杠杆倍数
- 保证金要求 = 仓位价值 × IMR
- 杠杆调整验证: 账户净资产 >= 新保证金要求

**目标用户**:
- 保守交易者: 使用低杠杆 (2x-5x)
- 专业交易者: 使用中等杠杆 (10x-20x)
- 高风险交易者: 使用高杠杆 (50x-100x)

**详细文档**: [leverage_prd.md](leverage_prd.md)

## 🔗 模块协作关系

### 完整交易流程 (跨模块协作)

```
1. 用户设置杠杆 (Leverage)
   ↓
2. 用户放置订单 (CLOB)
   ├─> 验证保证金 (使用 Leverage 设置)
   ├─> 获取合约配置 (Perpetuals)
   ├─> 获取价格 (Prices)
   └─> 进入订单簿
   ↓
3. 订单匹配 (CLOB)
   ├─> 与 Vault 订单或用户订单匹配
   └─> 生成成交
   ↓
4. 成交后处理
   ├─> 更新账户余额和持仓 (Subaccounts)
   ├─> 更新未平仓合约量 (Perpetuals)
   └─> 记录交易统计 (Stats)
   ↓
5. 资金费率结算 (Perpetuals)
   ├─> 计算资金费率
   └─> 结算到持仓账户
   ↓
6. 手续费分级 (Stats)
   ├─> 根据 30 天交易量确定 VIP 层级
   └─> 应用手续费折扣
```

## 🎨 用户角色与功能映射

### 普通交易者

**使用的模块**:
- CLOB: 放置限价单交易
- Leverage: 设置杠杆 (默认 20x)
- Stats: 查看交易统计和 VIP 层级

**典型场景**:
1. 设置 10x 杠杆
2. 放置 BTC-USD 买单
3. 订单匹配成交
4. 持仓盈利后平仓
5. 查看交易统计,发现可升级 VIP

### 做市商

**使用的模块**:
- CLOB: 放置 Post-Only 订单
- Stats: 享受 Maker 低费率
- Vault: 或者存入 Megavault,自动做市

**典型场景**:
1. 分析市场,确定报价策略
2. 放置多个 Post-Only 订单
3. 赚取价差和负费率返佣
4. 达到 VIP 3,Maker 费率 -0.01%

### 流动性提供者 (LP)

**使用的模块**:
- Vault: 存入 USDC,获得份额
- Stats: (间接) Vault 做市产生交易统计

**典型场景**:
1. 存入 50,000 USDC 到 Megavault
2. 获得份额,开始参与做市
3. Vault 自动提供流动性,赚取价差
4. 30 天后,份额价值上升 5%
5. 提款,获得收益

### 项目方

**使用的模块**:
- Listing: 创建新市场
- Vault: 存入初始流动性

**典型场景**:
1. 为代币 XYZ 创建市场
2. 选择流动性层级 Mid-Cap
3. 存入 10,000 USDC 到 Megavault
4. 市场创建成功,开始交易
5. 在社交媒体宣传
